## HASHTAG BEST PRACTICES

### DO:
✅ Mix high-volume and niche hashtags (80/20 rule)
✅ Research hashtag popularity before using (aim for 10K-500K posts)
✅ Create a branded hashtag and use it consistently
✅ Rotate hashtags between posts (don't use exact same set every time)
✅ Put hashtags in first comment on Instagram (cleaner look)
✅ Use 3-5 hashtags on TikTok (quality over quantity)
✅ Monitor which hashtags drive engagement
✅ Update your hashtag strategy quarterly

### DON'T:
❌ Use banned or spam hashtags (check Instagram's restricted list)
❌ Use irrelevant hashtags just because they're popular
❌ Use the exact same hashtag set on every post
❌ Use more than 30 hashtags on Instagram (looks spammy)
❌ Use hashtags that are too broad (#love, #instagood - too competitive)
❌ Ignore platform differences (Instagram ≠ TikTok ≠ LinkedIn)
❌ Forget to track which hashtags work best

---

## BANNED/RESTRICTED HASHTAGS TO AVOID

Instagram periodically bans hashtags. Always check before using. Common banned construction-related hashtags:

❌ #construction (sometimes restricted - use #constructionlife instead)
❌ #hardhat (sometimes restricted)
❌ #beautifulday (surprisingly banned)
❌ #workflow (sometimes restricted)

**How to check**: Search the hashtag on Instagram. If "Recent" posts don't show, it's restricted.
